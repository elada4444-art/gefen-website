# סרטון הסבר: הגיוסים לפוליסות החיסכון (מחצית ראשונה 2026)

אנימציית מושן-גרפיקס ממותגת לגפן ביטוח ופיננסים, המבוססת על כתבת FUNDER מ-30.8.2026
(https://www.funder.co.il/article/208647).

- `anim.html` — האנימציה עצמה (1080×1920, RTL, Heebo). הפונקציה `render(t)` מציירת כל פריים לפי זמן, כך שהרינדור דטרמיניסטי.
- `narration.txt` — תסריט הקריינות (8 סצנות). הקריינות הופקה עם edge-tts, קול he-IL-AvriNeural.
- `timeline.json` — משכי הסצנות, נגזרים מאורך קובצי הקריינות.
- `render.js` — רינדור פריים-אחר-פריים ב-Playwright/Chromium והזרמה ל-ffmpeg (H.264, 30fps).
- `build.sh` — הרכבת השמע (adelay + amix + loudnorm), בניית ציר הזמן והרצת הרינדור.
- `build_preview.py` — בונה עמוד תצוגה מקדימה עצמאי עם נגן ושמע מוטמע.

הנתונים בסרטון: סך גיוסים 21.8 מיליארד ₪ (לעומת 13.9, +57%), הפניקס 7.55 מיליארד (+18%),
איילון 3.19 מיליארד (מ-315 מיליון, ~+910%), מגדל שלישית, הכשרה ~2.5 מיליארד, ביטוח ישיר 160 מיליון (+208%),
והערכה לגיוס של כמיליארד ₪ לגמל של איילון בחודש הפעילות הראשון.
